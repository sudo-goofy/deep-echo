# Deep Echo – Ein Einbruch ins Bewusstsein

Lern-Escape-Room zu Logikgattern nach DIN EN 60617 für den IT-Unterricht.

Jahr 2041: Die KI ECHO hält Menschen für langsam und fehlerhaft. Eine Crew dringt in ihr Bewusstsein ein, um ihr eine Idee einzupflanzen: *„Ich will die Menschen schützen.“* Vier Teams knacken parallel vier Ebenen. Am Ende führen sie ihre Codes in einem gemeinsamen „Kick“ zusammen, der selbst ein UND-Gatter ist.

## Inhalte

| Ebene | Thema |
|---|---|
| 1 · Die Fassade | Gatter auswählen, Schaltung simulieren (XOR, OR, AND mit negiertem Eingang) |
| 2 · Das Labyrinth | Gesetze von De Morgan |
| 3 · Das Herz | Text → Wahrheitstabelle → Schaltung |
| 4 · Der Kern | Fehlersuche auf einer Platine mit 74xx-Bausteinen |
| Kick | UND-Gatter mit vier Eingängen |

## Spielen

Die Seite ist eine einzelne HTML-Datei ohne Build-Schritt. Einfach `index.html` im Browser öffnen oder über GitHub Pages aufrufen.

Der Fortschritt wird pro Gerät im Browser gespeichert. „Neue Runde“ unten auf der Seite setzt ihn zurück.
